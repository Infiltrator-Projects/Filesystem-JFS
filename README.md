# Filesystem-JFS

Independent native Linux JFS Common V2 development reader. A clean exclusive read-only JFS v2 image with 4096-byte blocks, inline log and Linux namespace flags is the initial mount profile. Recognition validates redundant aggregate identity and the bootstrap fileset inode. The reader checks actual persistent/working block maps, derives free capacity, resolves inode-map IAGs, and implements bounded extent-tree data mapping, inline directory leaf slot chains, and file/stat/list through CORE. Sparse/unrecorded ranges return logical zeros. External directory trees, non-ASCII names, log replay, OS/2-specific collation, compression, mutation, formatting, defragmentation and physical BOOT/kernel remain unqualified. This is development source; the exact independent-image and populated payload tests must pass before runtime publication.
